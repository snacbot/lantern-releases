## Comfort, with fewer interruptions

A more comfortable Windows workspace, with pointer recovery and smoother automatic updates.

Run the installer, then open Lantern from the system tray.

---

### What changed

- Shake your mouse or trackpad pointer back and forth several times to restore this computer's screens to 100%, including software dimming. Enabled by default; turn it off in Settings > General > Shake mouse to restore brightness.
- New installations use a user-writable folder so automatic updates can install and restart Lantern without administrator prompts. Update failures no longer open a dialog.
- Reinstalling closes existing Lantern copies and leftover helpers before replacing files, including copies stuck on a duplicate-instance dialog.
- Existing settings, presets, pairing data and login preferences are preserved.

If Lantern is installed in Program Files, run the 0.3.0 installer once to move it to the new location and update shortcuts, startup registration and firewall rules. Setup requires administrator access for firewall configuration; subsequent automatic updates do not. An older client's first update may still request administrator approval until this installer migration is complete.

Use a trusted Private network and the same connection port on each computer.
