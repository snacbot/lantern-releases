## A smoother everyday experience

A smoother Windows experience, with more reliable controls, safer saves and clearer pairing.

Run the installer, then open Lantern from the system tray.

### What changed

- Normal startup and signed automatic updates run without requesting administrator access. Setup installs into the current user’s writable Programs folder and refreshes startup, shortcuts and private-network firewall rules. Older Program Files installations should run setup once to migrate; an older updater may still request approval for its transition update.
- Improved brightness confirmation, rediscovery, helper recovery and stale local-command endpoint handling.
- Safer settings, preset, automation, pairing-token and update replacement transactions, with recovery on storage failures.
- Improved compact/high-DPI pairing codes, accessible localized pairing instructions, and phone-width layouts and reconnect feedback.
- Preserves existing settings, display identity, presets and pairing data. Test/custom-profile launches cannot alter login startup registration.

### Validation

Windows native, browser, owner-process, protocol, automation, accessibility and rendering regressions; signed-package verification and tamper rejection. Physical-device, phone, screen-reader and Mac acceptance remain separate checks.

### Installation

Download Lantern-setup.exe (or the identical versioned setup file) for installation and migration. Setup needs one-time administrator approval for firewall/protected-file maintenance; ordinary startup and subsequent automatic updates do not. The raw executable and signed manifest assets are for the automatic updater. This release updates Windows; Mac downloads remain on their existing release.
