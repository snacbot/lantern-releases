## More room. Less clutter.

A cleaner brightness panel and settings experience, with clearer feedback when your changes are saved.

**[Download for Windows ↗](https://github.com/snacbot/lantern-releases/releases/download/v0.3.2/Lantern-setup.exe)** &nbsp; · &nbsp; Windows patch release &nbsp; · &nbsp; Windows 10+ · x64

Run the installer, then open Lantern from the system tray. Existing supported installations receive this release through signed automatic updates while Lantern is running.

---

### What changed

- **See more of your workspace.** The brightness popup expands to fit your displays, up to the available screen height. Scrolling is only needed when the list exceeds the screen.
- **Settings, one click away.** A compact settings cog now sits beside the coffee link in the popup.
- **A cleaner settings window.** Removed redundant studio, release-page and install-update buttons. The clickable Khaos Studios credit and coffee link stay at the bottom left across settings tabs.
- **Know your changes were saved.** Apply shows “Settings applied.” after a successful save.
- **A more reliable start.** Auto Start remains enabled by default. Lantern retries missing startup registration when that preference is enabled and preserves an explicit disabled preference.

### Updating

Lantern verifies the signed update package before installing it and restarting. Existing settings, display identity, presets and pairing data are preserved. Windows and Mac update independently; this patch updates Windows only.

If your Windows copy is still installed in Program Files, run the installer once to move to the current user-writable location. Setup needs administrator approval for firewall and protected-file maintenance; ordinary startup and subsequent automatic updates do not. Older clients may need automatic updates enabled to receive the transition release.

### Validation

178 Windows tests passed. The release executable’s embedded version matches 0.3.2. Signed-package verification and tamper-rejection checks passed, and the previous 0.3.1 client accepts the new signed package. Physical-device and accessibility acceptance remain separate checks.
