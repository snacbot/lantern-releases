## A smoother start

A smoother installer and verified automatic updates for Windows.

**[Download for Windows ↗](https://github.com/snacbot/lantern-releases/releases/download/v0.1.3/Lantern-setup.exe)** &nbsp; · &nbsp; Windows release &nbsp; · &nbsp; Windows 10+ · x64

Run the installer, then open Lantern from the system tray.

---

### What changed

- Setup automatically stops running Lantern tray copies, including portable
  copies on the current desktop, before installation and launches the installed
  version afterward. This also applies to silent installs.
- Installer file details include Khaos Studios, copyright, and the release version.
- Normal installed copies automatically check for and apply verified updates.
- Settings include a way to copy an installation report for troubleshooting.

The release includes the Windows executable, signed update manifest and signature,
and both versioned and stable-name installers. Existing settings and pairing data
are retained during an automatic update. Program Files updates may request
Windows administrator approval.

Older versions need automatic updates enabled to receive this release. If the
installed version cannot update automatically, run `Lantern-setup.exe` once.
