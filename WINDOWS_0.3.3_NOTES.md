## A simpler settings window.

Two small refinements to keep Lantern settings clean and consistent.

**[Download for Windows ↗](https://github.com/snacbot/lantern-releases/releases/download/v0.3.3/Lantern-setup.exe)** &nbsp; · &nbsp; Windows patch release &nbsp; · &nbsp; Windows 10+ · x64

Run the installer, then open Lantern from the system tray. Existing supported installations receive this release through signed automatic updates while Lantern is running.

---

### What changed

- **Less clutter in About & Updates.** Removed the one-time installation-report checkbox and its explanatory text. Existing saved reporting preferences are preserved.
- **Support from all of us.** The settings footer button now reads “Buy Us a Coffee” across every settings tab.

### Updating

Lantern verifies the signed update package before installing it and restarting. Existing settings, display identity, presets and pairing data are preserved. Windows and Mac update independently; this patch updates Windows only.

If your Windows copy is still installed in Program Files, run the installer once to move to the current user-writable location. Setup needs administrator approval for firewall and protected-file maintenance; ordinary startup and subsequent automatic updates do not. Older clients may need automatic updates enabled to receive the transition release.

### Validation

178 Windows tests passed. The release executable’s embedded version matches 0.3.3. Signed-package verification and tamper-rejection checks passed, and the previous 0.3.2 client accepts the new signed package. Physical-device and accessibility acceptance remain separate checks.
