### What changed

- **Know your version.** About & Updates now clearly displays the installed Lantern version.
- **See the last check.** The most recent completed automatic or manual update check shows its local date and time and remains available after a restart. Failed attempts retain their error status so a timestamp does not imply a successful check.

### Updating

Lantern verifies the signed update package before installing it and restarting. Existing settings, display identity, presets and pairing data are preserved. Windows and Mac update independently; this patch updates Windows only.

If your Windows copy is still installed in Program Files, run the installer once to move to the current user-writable location. Setup needs administrator approval for firewall and protected-file maintenance; ordinary startup and subsequent automatic updates do not. Older clients may need automatic updates enabled to receive the transition release.

### Validation

179 Windows tests passed. The release executable’s embedded version matches 0.3.4. Signed-package verification and tamper-rejection checks passed, and the previous 0.3.3 client accepts the new signed package. Physical-device and accessibility acceptance remain separate checks.
