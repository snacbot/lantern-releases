## Find your workspace faster

Easier discovery and more polished keyboard navigation on Windows.

**[Download for Windows ↗](https://github.com/snacbot/lantern-releases/releases/download/v0.1.4/Lantern-setup.exe)** &nbsp; · &nbsp; Windows release &nbsp; · &nbsp; Windows 10+ · x64

Run the installer, then open Lantern from the system tray.

---

### What changed

- LAN control is enabled by default in the installer; saved opt-outs are preserved.
- Settings > Network includes Scan LAN to refresh discovery of other Lantern computers.
- Settings controls respect Windows focus visibility during mouse and keyboard navigation.
- Installation reports send automatically once without a popup.

Use the same connection port on each computer and a trusted Private network. Existing settings and pairing data are preserved.
