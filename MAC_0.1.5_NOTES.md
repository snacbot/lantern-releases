### In this preview

- Brightness controls for individual displays, your Mac and connected computers.
- Saved presets, keyboard shortcuts and optional paired phone control.
- Incoming LAN brightness control stays off until you opt in on a trusted network.
- Updates check at launch and every 15 minutes while Lantern runs. Verified updates download, install and restart Lantern automatically, with no update opt-out setting. Active display tests restore their screens before an update restart.
- Existing settings and computer identity are preserved. Older update opt-outs and skipped versions are cleared on startup.

### Installation

Open `Lantern-0.1.5.dmg`, drag Lantern into Applications, then open it from Applications. Older development builds or clients with update checks disabled require this manual installation.

Built for macOS 13 or later, Apple Silicon and Intel. Native checks have run on the release Mac running macOS 27. Older macOS versions, Intel Macs, another Mac, sleep/wake, dock replug, fullscreen/Spaces, mirroring, clamshell and login/update restart behavior still need broader device validation. This is a public preview, not a claim that every monitor or dock has passed compatibility testing.

External hardware DDC control requires Apple Silicon and a compatible connection. Intel external displays and DisplayLink can use software dimming. Software dimming darkens the picture while Lantern runs; it does not switch off the physical backlight.

Restore local brightness with **Control + Option + Command + R** or the restore button. Experimental display power tests remain separate from ordinary brightness controls.

Report issues at https://github.com/snacbot/lantern-releases/issues with your macOS version, monitor and dock details. Do not include private computer names, pairing keys or credentials.
